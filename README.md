# 🎮 Games Desktop

> Una colección de juegos web clásicos e independientes adaptados y empaquetados mediante un contenedor nativo en C++ con WebView para ejecutarse de forma local en tu computadora.

---

## 📌 ¿De qué trata este proyecto?
Este repositorio contiene versiones empaquetadas de juegos basados en tecnologías web (HTML5, WebGL y Unity), integradas en una aplicación nativa escrita en **C++** y utilizando **WebView**. Esto permite una ejecución fluida, independiente y sin depender de servidores externos o pestañas de navegador.

---

## 🚀 Juegos Disponibles
* **Geometry Dash World (Versión de Escritorio Local)**
  * Motor: Unity (WebGL)
  * Estado: Funcional y optimizado para ejecución offline dentro del contenedor nativo.

---

## 💻 Requisitos del Sistema y Compatibilidad
* **Sistema Operativo:** Windows 10 / Windows 11 (Requiere el runtime de WebView2).
* ⚠️ **Nota sobre Windows 7:** Esta versión actual está optimizada exclusivamente para Windows 10 y 11. Próximamente se lanzará una versión alternativa con compatibilidad adaptada para equipos con Windows 7.

---

## 📥 Descarga e Instalación
Para empezar a jugar de inmediato:
1. Dirígete a la sección de **[Releases](https://github.com/AtomicMX04/My-Games/releases/tag/v1.0.0)** de este repositorio.
2. Descarga el paquete correspondiente a la última versión disponible.
3. Descomprime el archivo en cualquier carpeta de tu ordenador.
4. Ejecuta el archivo ejecutable (`.exe`) y ¡listo!
